Security

If you find a vulnerability in this site or in Tollgate, please tell us privately so it can be fixed.

How to report

Email dayeon603@gmail.com with the subject "Tollgate: security report". Include:

  • What you found and where.
  • Steps to reproduce it.
  • What someone could do with it.

Report a vulnerability

What we ask

  • Give us a reasonable time to fix the issue before you make it public.
  • Test only against your own data. Do not access, change or delete anyone else's.
  • Do not run denial-of-service tests, spam or social engineering.
  • Stop and tell us if you reach data that is not yours.

Scope

In scope: this demo site and the Tollgate product. There is no bug bounty, so reports are not paid.

What the demo does with data

  • Screening, signing and verifying all run in your browser. Addresses you type and files you check are not sent anywhere.
  • Receipts you make live in the open tab only and are gone when you close it, unless you download them.
  • No cookies, no analytics, no tracking scripts. The pages load only their own files. The one exception is the workspace's Live chain, which reads public Ethereum data from ethereum-rpc.publicnode.com (fallback eth.drpc.org); the workspace's Content Security Policy allows exactly those two origins.
  • The site is hosted on GitHub Pages. As the host, GitHub receives standard request data such as your IP address, under its own policies.

What the demo doesn't do

  • Receipts made here are signed with a public demo key that anyone can use, so they show the format and say nothing about who signed.
  • Unsealed records can be rewritten by whoever holds the signing key.
