# Tollgate demo site

Static site, no build step, relative URLs only, and no requests beyond its own files. Serve the folder over HTTP from any path (for example `python3 -m http.server`); it will not run from `file://`.

- `index.html`: product page. The hero runs the real verifier on the sample chain and shows the time it took.
- `app.html`: demo analyst workspace (dashboard, alerts and cases with four-eyes clearing, screening and CSV batches, monitoring, list versions with update lookback and diff, receipt explorer, evidence packs, policy and roles, activity log, API examples) plus the original tools (Get started, Verify receipts, Raw receipts). Everything runs in the browser on synthetic demo data; the sanctions list is the real bundled snapshot. State is kept in localStorage as a short op log (Reset demo erases it). Code is in `js/ws/`; `scripts/verify_pack.mjs` checks an evidence pack offline. The original Try it flow: Screen an address against a bundled copy of OFAC's list (exact match, ignoring case), sign a receipt in the browser with the published demo key, verify or tamper, download a receipt package, and check a package file offline.
- `app.html` terminal layer (`css/terminal.css`, `js/ws/stream.js`, `live.js`, `view-live.js`, `graph.js`, `view-graph.js`, `view-flow.js`, `view-value.js`, `palette.js`): a Live view that screens a seeded synthetic payment stream through the real engine and signs each decision into a rolling ledger (300 receipts, kept apart from the workspace ledger and evidence packs, off until started), live charts, a status bar, a direct-counterparty graph (exact list matches only, no scoring), chain and hour breakdowns, a command palette (Ctrl or Cmd K), alert bulk actions, keyboard triage, saved views, SLA timers and drafted case summaries. The Time and cost view shows timings measured in the visitor's browser and a calculator that only uses numbers the visitor types. No trading, prices or portfolio features.
- `signin.html` (demo user picker, no credentials) and `waitlist.html` (early-access waitlist, mailto with its own subject).
- `contact.html` (Talk to us form) and `report.html` (problem report form): validated in the page; submit opens a prefilled email (mailto) and offers copy-to-clipboard if no mail app opens. Nothing is sent automatically. To use a hosted form service later, set `FORM_ENDPOINT` in `js/forms.js` and add its origin to `connect-src` in those pages' Content Security Policy.
- `faq.html`, `security.html`, `privacy.html`, `terms.html`.

`data/ofac_crypto_addresses.json` is generated by `scripts/build_ofac_bundle.py` from the Tollgate repo's OFAC snapshot; it records the source URL, publish date, download time and the SHA-256 of the raw SDN.XML. The sample payments are made up and the signing key is a published demo key.

Tests: `python3 tests/e2e_pro.py <served-url>/ <screenshot-dir>` (terminal layer, sign in, waitlist, 30 second 20x stream soak with frame times, palette, bulk actions, both themes at desktop and phone), `node --test tests/` (screening, signing, packaging, tamper detection, workspace logic), `python3 tests/e2e_workspace.py <served-url>/ <screenshot-dir>` (workspace flows in Playwright) `python3 tests/e2e_graph.py <served-url>/ <screenshot-dir>` (Counterparties view at 2560, 1440 and 390 px, and Settings), and `python3 tests/e2e.py <served-url>/ <screenshot-dir>` (Playwright: every page, links, verifier pass/fail, the Get started flow, phone width, reduced motion, console errors, own-origin requests).
